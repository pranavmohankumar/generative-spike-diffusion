Project #7 Specification

Generative Neural Spike Train Augmentation & Diffusion Models

Target Industry Profile: Advanced AI BCI Startups, Computational Neuroscience Labs

1. System Architecture & Concept

1D Conditional Time-Series Diffusion Model generating synthetic high-density spike raster plots validated via Power Spectral Density matching.

2. Synthetic Bio-Data Engineering Strategy

Binary spike matrices (64 channels x 1000 time steps) representing multi-neuron population dynamics.

3. Low-End LLM Prompt & Module Blueprint

  • Module 1: Spike Raster Data Engine: Create synthetic multi-neuron spike matrices with correlated ensemble firing patterns.
  • Module 2: 1D Time-Series Diffusion Model: Implement PyTorch Denoising Diffusion Probabilistic Model (DDPM) for binary spike matrices.
  • Module 3: Biological Fidelity Metrics: Compute Power Spectral Density (PSD) and cross-correlation similarity scores.

4. Core Technical Starter Skeleton

import torch
import torch.nn as nn

class MiniUnedDDPM(nn.Module):
    def __init__(self, channels=64):
        super().__init__()
        self.conv = nn.Sequential(
            nn.Conv1d(channels, 128, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.Conv1d(128, channels, kernel_size=3, padding=1)
        )
    def forward(self, x, t):
        return self.conv(x)
